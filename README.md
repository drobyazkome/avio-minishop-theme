# Avio Next — Твой интернет

Версия 1.6.0, ключ `avio-next`. Это новая редакция темы Avio для minishop. Она
ставится рядом с прежней `avio-landing` и не заменяет её. Ветка репозитория — `avio-next`.

Оформление осталось прежним: лавандовая палитра, панорамный фон, крупный логотип
и мягкие карточки. Изменения касаются удобства, тёмного режима и веса пакета.

## Что изменилось по сравнению с avio-landing 1.5.15

**Тёмный режим.** Все цвета, которых нет среди токенов Core, вынесены в переменные
со значениями для светлого и тёмного варианта: выгодный период, выделенный тариф,
статус серверов, отсутствие подписки, админ-панель. В 1.5.15 они оставались светлыми
и на тёмном фоне выглядели как наклейки, а цена за месяц в карточке «1 год»
почти не читалась.

**Движение.** Восемь зацикленных анимаций убраны: «дыхание» кнопок, выбранного периода
и тарифа, блики, покачивание иконки навигации. Кнопку оплаты при открытии чекаута
дважды проходит блик, затем она неподвижна. Отклик на нажатие сохранён.

**Главная.** «Продлить подписку» — вторичная кнопка, пока подписка в порядке. Когда Core
помечает подписку как истекающую (`status-card-warning`), продление становится главной
кнопкой, а «Установить и настроить» уходит на второй план.

**Цвет со смыслом.** Зелёный обозначает только «хорошо»: выгодный период и работающие
серверы, плюс зелёная админ-панель по желанию владельца. Кнопка продления больше не
зелёная. Статус серверов при проблеме переключается на персиковый. Отсутствие подписки
показано тёплым персиковым приглашением, а не красной ошибкой.

**Оплата.** Порядок блоков прежний: кнопка оплаты сразу под периодами. Карточка самого
длинного периода выбирается как последняя (`:last-child`), а не четвёртая, и выделяет
цену за месяц. Подпись кнопки настройки тарифа берётся из её локализованного `title`,
поэтому англоязычные пользователи видят английский текст. Раньше он был зашит по-русски.
На экранах до 360 px кнопка показывает только иконку.

**Поля ввода** стоят на цвете карточки с заметной рамкой и больше не похожи на
вторичные кнопки.

**Мелкий текст.** Надписи 9–10,5 px подняты до 11–12 px: факты тарифа, подписи слайдеров,
цена за месяц, статус серверов.

**Установка.** На телефонах 360–519 px приложения идут по три в ряд (та же 6-колоночная
сетка, что у Core на планшетах). Первый шаг инструкции теперь виден без прокрутки.

**Настройки.** У «Безопасности» и «Политики конфиденциальности» свои иконки (ключ и
документ с замком), щит остался только у админ-панели. Тонкие линии между группами
убраны, юридические строки стали тише.

**Вес пакета.** Фон переведён из PNG 1,6 МБ в WebP 34 КБ. Шрифты урезаны до латиницы
и кириллицы в WOFF2: 553 КБ стали 98 КБ, ось веса сохранена. Иконки приложений
уменьшены до 144 px WebP (было до 341 КБ за штуку). PNG-иконки действий заменены
SVG-масками Lucide, которые красятся цветом текста кнопки. Благодаря этому в тёмном
режиме стрелка на светлой кнопке оплаты тёмная, а не белая.

**CSS.** Заплатки версий 1.5.6–1.5.9 сведены в одно правило на компонент.
Файл сократился с 1735 до 1536 строк, `!important` — с 57 до 31.

## Установка

1. **Админка → Внешний вид → Добавить темы**, загрузите `avio-next-theme.zip` или
   укажите этот репозиторий с веткой `avio-next`.
2. Откройте предпросмотр **Avio Next — Твой интернет** и нажмите **Активировать**, когда
   всё устроит. Прежняя `avio-landing` остаётся в библиотеке для отката.
3. Логотип берётся из настроек бренда, как и раньше. Для него подходит
   `images/avio-logo.png` из пакета.

Настройки владельца (палитра, шрифты, масштаб логотипа, прозрачность) сохраняются
отдельно для каждого ключа. Если вы меняли их у `avio-landing`, повторите изменения
у `avio-next`.

## Настройка в редакторе Core

Переменные ниже Core находит в CSS и показывает в карточке темы для каждого варианта:

- `--avio-backdrop-*` — оттенок и затемнение поверх фоновой картинки;
- `--avio-peach*` — отсутствие подписки и проблемы серверов;
- `--avio-good*` — выгодный период и работающие серверы;
- `--avio-gold*` — выделенный тариф;
- `--avio-admin-*` — строка и кнопка админ-панели;
- `--avio-highlight` — светлый блик по верхнему краю цветных карточек.

Выделенный тариф — второй в порядке админки: в этом магазине это «Премиум». Core не
отдаёт ключ тарифа в разметке, поэтому при смене порядка тарифов золотым станет другой.

## Состав

- `theme.json` — палитры, шрифты, радиусы, варианты `light` и `dark`.
- `style.css` — оформление существующей разметки minishop.
- `images/avio-background.webp` — панорамная иллюстрация.
- `images/avio-logo.png` — прозрачный логотип для настроек бренда.
- `images/app-*.webp` — иконки клиентских приложений, см. `images/APP-ICONS.md`.
- `icons/*.svg` — иконки Lucide (ISC), используются как маски.
- `fonts/*.woff2` и `fonts/*-OFL.txt` — Onest и Rubik под SIL OFL 1.1.
- `preview.webp` — карточка темы 1280×800.

Внешних CSS, запросов к Google Fonts и исполняемого кода в пакете нет.

## Совместимость и проверка

`theme_api: 1`, Core dev от 24.09.2026 (`98382cd`). Нужна проверка SVG в пакетах:
она есть в dev с 15.09.2026 (`c7c0315`).

Проверено на demo-сборке Core из этого коммита в Chromium: главная (активная,
истекающая, без подписки, со статусом серверов), оплата с дополнениями и без, выбор
и смена тарифа, установка, бонусы, устройства, поддержка, настройки и вход. Оба режима,
ширина 320, 390, 430 и 1280 px. Горизонтальной прокрутки, битых картинок и ошибок
JavaScript нет.

До внесения изменений сведённый CSS сравнивался с 1.5.15 по вычисленным стилям всех
элементов на 70 снимках экранов: расхождений нет. Затем были внесены изменения,
описанные выше.

Контраст новых пар текст/фон не ниже 4,77:1 в светлом режиме и 6,61:1 в тёмном.

Demo заменяет API демонстрационными данными: реальные платежи и авторизация этой
проверкой не покрываются.
